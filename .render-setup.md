# Render Deployment Button

To add a one-click deploy button to your README, follow these steps:

1. Update the `RENDER_DEPLOYMENT.md` file with your actual GitHub repository URL
2. Replace `YOUR_GITHUB_REPO_URL` in the deploy button link with your actual repo URL in this format:
   ```
   https://github.com/your-username/your-repo
   ```

Example deploy button in your README:

```markdown
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/your-username/civicvoice-backend)
```

This assumes you have committed the `render.yaml` file to your repository.
